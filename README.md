# مُصفّي

موقع يعمل على سيرفرك الخاص بدون أي خدمة خارجية، ويقدم ميزتين:

1. **فصل الأصوات** إلى أربعة مسارات لكل منها مؤشر قوة وشريط تحكم:
   الكلام، والموسيقى، والضوضاء الثابتة، والأصوات المحيطة. يمكن مثلًا إزالة الموسيقى والإبقاء على الكلام.
2. **تمويه الصورة**: النساء فقط أو الجميع، للجسم كاملًا أو للوجه فقط، مع مراجعة يدوية لكل شخص قبل التصدير.

## الخصوصية (مطبّقة فعليًا في الكود)

| ما يحدث | أين في الكود |
|---|---|
| لا يُرسل أي ملف لأي جهة خارجية، وكل النماذج تعمل محليًا | `app/selftest.py` يختبر النماذج مع منع الإنترنت |
| يُحذف مجلد المقطع بالكامل فور انتهاء التحميل | `download()` في `app/main.py` |
| زر «احذف الآن» في كل مراحل الاستخدام | `DELETE /api/jobs/{id}` |
| حذف تلقائي إذا لم يحمّل المستخدم خلال 30 دقيقة من مغادرته الصفحة | `_sweeper()` في `app/jobs.py` |
| حد أقصى لعمر أي مقطع (4 ساعات) مهما كانت حالته | `MUSAFFI_TTL_MAX_MIN` |
| مسح كل الملفات المؤقتة عند كل تشغيل للخادم | `JobManager.start()` |
| حدود لحجم الملف ومدته وعدد المهام، لحماية مساحة السيرفر | `app/config.py` |
| لا ملفات تعريف ارتباط ولا أدوات تتبع، ويمنع المتصفح من تحميل أي مورد خارجي | `Content-Security-Policy` في `app/main.py` |
| روابط المقاطع عشوائية لا يمكن تخمينها | `secrets.token_urlsafe` |

## التشغيل

### بـ Docker (الأسهل)
```bash
git clone <رابط المستودع> musaffi && cd musaffi
docker compose up -d --build
```
ثم افتح `http://عنوان-السيرفر:8000`. تُحمَّل النماذج مرة واحدة أثناء البناء (حوالي 700 ميجابايت)، وبعدها لا يتصل الموقع بالإنترنت.

### بدون Docker
```bash
sudo apt install ffmpeg git
python3 -m venv .venv && source .venv/bin/activate
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
pip install --no-deps deepfilternet==0.5.6
python scripts/download_models.py
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

> شغّل عاملًا واحدًا فقط (`--workers 1`)، لأن طابور المعالجة يعمل داخل العملية نفسها.

### خلف Nginx مع HTTPS (مهم للخصوصية)
```nginx
server {
    server_name example.com;
    client_max_body_size 300M;
    proxy_read_timeout 600s;
    access_log off;   # عدم تسجيل روابط المقاطع
    location / { proxy_pass http://127.0.0.1:8000; }
}
```

## الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MUSAFFI_MAX_UPLOAD_MB` | 300 | أقصى حجم للملف |
| `MUSAFFI_MAX_DURATION_SEC` | 900 | أقصى مدة للمقطع (15 دقيقة) |
| `MUSAFFI_MAX_QUEUE` | 10 | أقصى عدد مهام في الطابور |
| `MUSAFFI_TTL_AFTER_DONE_MIN` | 30 | الحذف التلقائي بعد مغادرة الصفحة دون تحميل |
| `MUSAFFI_TTL_MAX_MIN` | 240 | أقصى عمر لأي مقطع |
| `MUSAFFI_THREADS` | عدد الأنوية | أنوية المعالج المستخدمة |
| `MUSAFFI_PERSON_MODEL` | `yolo11s-seg.pt` | استخدم `yolo11n-seg.pt` لسرعة أكبر بدقة أقل |

## النماذج المستخدمة (مجانية، وتعمل محليًا)

| المهمة | النموذج | الرخصة |
|---|---|---|
| فصل الصوت البشري عن الموسيقى | UVR MDX-Net Voc_FT (عبر audio-separator) | MIT |
| الجودة القصوى (اختياري) | BS-Roformer (viperx) | مجاني من مشروع UVR |
| عزل الكلام | DeepFilterNet3 | MIT / Apache-2.0 |
| فصل الضوضاء الثابتة | noisereduce (خوارزمية، ليست نموذجًا) | MIT |
| اكتشاف وتقسيم الأشخاص وتتبعهم | Ultralytics YOLO11-seg + ByteTrack | AGPL-3.0 |
| اكتشاف الوجوه | InsightFace SCRFD (det_10g) | **غير تجاري فقط** |
| تقدير الجنس | InsightFace genderage | **غير تجاري فقط** |

> **تنبيه:** نماذج InsightFace مسموحة للاستخدام غير التجاري فقط. وبسبب رخصة AGPL الخاصة بـ YOLO11، يجب أن يبقى كود المشروع مفتوحًا إذا أتحت الموقع للعامة. إذا تحوّل المشروع لاحقًا إلى تجاري، يجب استبدال هذه النماذج أو شراء تراخيصها.

## كيف يعمل

**الصوت:**
```
الصوت الأصلي ─► MDX-Net ─┬─► الموسيقى (الأصلي − الصوت البشري)
                         └─► الصوت البشري ─► DeepFilterNet3 ─┬─► الكلام
                                                              └─► الباقي ─► noisereduce ─┬─► ضوضاء ثابتة
                                                                                         └─► أصوات محيطة وأخرى
```
مجموع المسارات الأربعة يساوي الصوت الأصلي، فوضع كل الأشرطة على 100% يعيد الصوت كما هو.

**التمويه:**
1. YOLO11-seg يكتشف كل شخص ويرسم حدود جسمه في كل إطار.
2. ByteTrack يعطي كل شخص رقمًا ثابتًا طوال المقطع، فلا يومض التمويه.
3. SCRFD يكتشف الوجوه، ويقدّر نموذج genderage الجنس من كل وجه، وتُجمع التقديرات لكل شخص عبر كل ظهوره.
4. **قاعدة الحيطة (الوضع «حذر»):** يُموَّه كل من لم يتأكد النظام أنه رجل، مثل من يظهر من الخلف أو المنقبة.
5. يراجع المستخدم صور الأشخاص ويغيّر القرار بنقرة، ويرى التمويه مباشرة على الفيديو قبل التصدير.
6. التمويه المطبَّق تكسير بكسلات قوي مع تنعيم، ولا يمكن عكسه.

## الأداء على سيرفر بدون كرت شاشة

مقطع مدته 3 دقائق على معالج بنواتين (تقريبًا):
- فصل الأصوات: نحو 10 دقائق.
- تحليل التمويه: نحو 10 دقائق.
- تصدير الفيديو مع التمويه: بضع دقائق.

المعالجة أسرع بشكل ملحوظ مع أنوية أكثر (8 أنوية أو أكثر مستحسنة). وضع «الجودة القصوى» بطيء جدًا بدون كرت شاشة، ويُنصح به فقط عند توفر GPU.

## حدود معروفة
- إذا كانت الموسيقى نفسها فيها غناء أو إنشاد، فقد يبقى جزء منه في مسار الكلام. حرّك شريط «أصوات محيطة وأخرى» لتقليل الباقي.
- تقدير الجنس من الوجه أقل دقة في الإضاءة الضعيفة واللقطات البعيدة والزحام، ولذلك الوضع الحذر هو الافتراضي، والمراجعة اليدوية متاحة دائمًا.
